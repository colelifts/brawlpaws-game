# Playable hero state atlases v1

These four source sheets were authored with OpenAI image generation using each hero's existing directional gameplay atlas as the identity and costume reference. Production copies in `../../../characters/` remove the flat chroma background.

Every sheet is a strict four-column by two-row atlas, read left-to-right and then top-to-bottom:

1. Undertow Well cast
2. Foxfire Volley cast
3. Wild Heart cast
4. Shock Paws cast
5. hit recoil
6. stun
7. defeat
8. victory

Shared constraints: isolated full-body character; matching scale and baseline; screen-right three-quarter game view; no scenery, text, UI, floor circle, or cast shadow; effects held tightly around the silhouette. Kitsune and Hopscotch use green chroma source sheets. Bamboo and Rusty use magenta chroma source sheets.

Hopscotch's offensive cast frames specifically require a fully drawn, visibly tensioned bowstring. Rusty's offensive casts require two independently readable pistols. The game mirrors canonical screen-right frames for leftward casts while retaining the separate eight-direction primary-fire atlases.
