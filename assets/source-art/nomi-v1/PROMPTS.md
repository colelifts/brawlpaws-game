# Nomi v1 source art

Generated with the built-in image generation workflow in direct generation mode. Each source was requested on a uniform chroma-green background, preserved here as `*-key.png`, then converted to the transparent production PNGs with the imagegen skill's chroma-key helper using border auto-keying, a soft matte, edge feathering, and despill.

## Production outputs

- `assets/characters/nomi-crane-v1.png` — 4×4 eight-direction idle/run atlas.
- `assets/characters/nomi-fire-v1.png` — 4×4 eight-direction windup/release atlas.
- `assets/characters/nomi-states-v1.png` — 4×2 ability and reaction atlas.
- `assets/characters/nomi-portrait-v1.png` — square hero portrait.
- `assets/vfx/nomi-glaive-vfx-v1.png` — 3×2 throw, return, impact, feather, capstone, and catch effects.

## Prompt direction

Nomi is an original elegant anthropomorphic red-crowned crane woman spirit-lancer with white and black feather markings, a vivid red crown, layered black/white/red or blue-violet battle robes, cyan moonlight highlights, and a large crescent moon ring-glaive. All sheets requested polished hand-painted 2D action-game art, crisp silhouettes, cel-shaded volume, full-body readable poses, generous per-cell margins, no text or UI, and exact atlas layouts.

The movement prompt requested sixteen directional idle/run poses. The firing prompt requested a visible full-body windup followed by a released ring-glaive, at all eight directions. The state prompt requested Undertow, Foxfire, Wild Heart, Shock Paws, hit, stun, defeat, and victory. The portrait prompt requested a waist-up three-quarter pose with the moon glaive clearly visible. The VFX prompt requested exactly six cells: spinning outbound glaive, feathered return streak, enemy impact, homing spirit feather, six-feather constellation, and catch pulse.
