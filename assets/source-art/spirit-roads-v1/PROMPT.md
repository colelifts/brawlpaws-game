# Spirit Roads v1

Generated with OpenAI image generation as a 2x2 chroma-key atlas.

- Top-left: continuous jade-stone spirit road.
- Top-right: broken stepping-stone road.
- Bottom-left: roadside foliage and bamboo landmark.
- Bottom-right: cyan spirit guide lantern.

Source prompt requested BrawlPaws' wide three-quarter view, cel-shaded Japanese-fantasy materials, dark navy outlines, jade stone, magenta foliage, cyan spirit light, and an exact `#00ff00` background. The production atlas is keyed to alpha and kept at the original 1256x1256 grid so each frame remains 628x628.
