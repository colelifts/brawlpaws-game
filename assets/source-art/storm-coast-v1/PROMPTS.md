# Storm Coast v1 source art

Generated with the project’s BrawlPaws visual references: painterly distant-isometric arenas, small readable fighters, saturated cyan/purple storm lighting, Japanese maritime fantasy architecture, and transparent production atlases.

- Seven 3:2 environment paintings: Tempest Harbor, Tideglass Causeway, Drowned Bell Sanctum, Siren Reef Monastery, Thunderbreak Lighthouse, Skyfang Ascent, and Eye of the Tempest.
- `exec-744214c3...png`: 3×2 combat atlas for Tideblade Otter, Galecrest Gull, and Reefbreaker Walrus; idle above, attack below, flat green key.
- `exec-69429ed0...png`: 3×2 movement atlas for the same enemy family; two distinct running strides, flat green key.
- `exec-91f5a48c...png`: 3×2 Raijin Kirin guardian atlas covering idle, sweep, slam, channel, and enrage poses, flat green key.
- `exec-297ba10a...png`: 2×1 Raijin Kirin movement atlas, flat green key.
- `exec-1a214644...png`: 3×2 Storm Coast VFX atlas: charge orb, lightning spear, impact, tide warning sigil, wave detonation, and thunder judgment, flat magenta key.

Production PNGs were derived with the ImageGen skill chroma-key helper using border key detection, soft matte, edge feathering, spill cleanup, and despill. Raw generated files are preserved beside this note.
